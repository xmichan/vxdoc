VX **All in One** Quick Deploy installs **vx-core** on your VPS and deploys multiple nodes 
in a single run. The deployed nodes use self-signed certs with SHA256 peer verification enabled, so you
don't have to worry MITM attacks.

A typical All-in-One deployment includes:

- **Protocols** — VMess, Trojan, AnyTLS, and Hysteria2
- **Transports** — WebSocket and gRPC
- **Security** — TLS on generated certificates; optional **REALITY** when you provide a REALITY domain
- **CDN** — optional CDN hostname for an extra WebSocket + TLS node in front of the server

VX can also enable **BBR** and adjust firewall settings during deploy when needed.
