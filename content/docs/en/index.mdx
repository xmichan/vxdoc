Welcome to the VX documentation. This site covers the **VX**: a network utility app and **vx-core**, 
a network utility software that powers the VX app.

## What is VX?

VX is the first free-of-charge, fully open-source, all-platform network utility app. It provides an 
easy-to-use GUI for monitoring/controlling your local network traffic, establishing proxy tunnels, 
managing node subscriptions, and server deployments.

## What is vx-core?

vx-core is a network utility software written in Golang. It originates from [v2ray-core](https://github.com/v2fly/v2ray-core), but is
quite differnet from v2ray-core since significant changes have been introduced.
