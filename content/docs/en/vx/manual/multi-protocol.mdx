VX supports the major proxy protocols through vx-core.

## Supported Protocols

- `VMESS`: AEAD encryption, widely supported by providers
- `VLESS`: Reduced TLS-in-TLS fingerprint
- `Shadowsocks`: Classic protocol with multiple ciphers
- `Shadowsocks2022`: Improved Shadowsocks protocol
- `Trojan`: TLS-wrapped, good for disguised traffic
- `Hysteria2`: QUIC-based, optimized for high-speed links
- `SOCKS5`: Standard SOCKS proxy
- `HTTP`: HTTP CONNECT proxy
- `AnyTLS`: Reduced TLS-in-TLS fingerprint
- `WireGuard`: Popular VPN protocol

## Transports

Many protocols support additional transport layers:

- TCP, WebSocket, gRPC
- HTTPUpgrade / SplitHTTP
- KCP
- TLS, uTLS, REALITY
