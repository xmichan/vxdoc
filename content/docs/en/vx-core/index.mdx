vx-core is the proxy engine that powers [VX](https://github.com/5vnetwork/vx), [UmiVPN](https://github.com/5vnetwork/umivpn) and [努努加速器](https://github.com/5vnetwork/nunu).
It can also be used as a proxy server on any OS.

## Deployment Modes

vx-core runs in different contexts depending on the platform:

- **Server**: Standalone server program
- **Client library**: Embedded in VX via gomobile/c-shared bindings

## Recommended Setup

We recommend using the [VX client](/docs/vx) to install and configure vx-core on a VPS. The client provides a GUI for server deployment, config editing, and monitoring over SSH.

For manual server setup, see [Quick Start](/docs/vx-core/quick-start).
