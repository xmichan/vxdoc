Connection policy is set in `ServerConfig.policy` (`PolicyConfig`). Schema: [`protos/proto/vx/policy.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/policy.proto).

All timeout values are in **seconds** unless noted otherwise in your deployment tooling.

## PolicyConfig

<ProtoField name="handshakeTimeout" type="int32">

Close if no data is received after connect

</ProtoField>

<ProtoField name="connectionIdleTimeout" type="int32">

Close when idle (no transfer in either direction)

</ProtoField>

<ProtoField name="udpIdleTimeout" type="int32">

Close UDP when no uplink data

</ProtoField>

<ProtoField name="upLinkOnlyTimeout" type="int32">

After downlink finished, close if no uplink data

</ProtoField>

<ProtoField name="downLinkOnlyTimeout" type="int32">

After uplink finished, close if no downlink data

</ProtoField>

<ProtoField name="defaultBufferSize" type="int32">

Default per-connection buffer (not all protocols honor this)

</ProtoField>

<ProtoField name="userPolicyMap" type="map&lt;uint32, UserPolicy&gt;">

Per `userLevel` overrides

</ProtoField>

## UserPolicy

<ProtoField name="bufferSize">

Buffer size for users at this level

</ProtoField>

User levels come from [UserConfig](/docs/vx-core/configuration/users) `userLevel` on each account.

## Example

```json
{
  "policy": {
    "handshakeTimeout": 4,
    "connectionIdleTimeout": 300,
    "udpIdleTimeout": 60,
    "userPolicyMap": {
      "0": { "bufferSize": 4096 }
    }
  }
}
```
