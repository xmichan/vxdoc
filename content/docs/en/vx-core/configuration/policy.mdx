Connection policy is set in `ServerConfig.policy` (`PolicyConfig`). Schema definition: [`protos/proto/vx/policy.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/policy.proto).

All timeout values are in **seconds**.

## PolicyConfig

<ProtoField name="handshakeTimeout" type="int32">

Close if no data after connection

</ProtoField>

<ProtoField name="connectionIdleTimeout" type="int32">

Close when idle (no traffic in either direction)

</ProtoField>

<ProtoField name="udpIdleTimeout" type="int32">

Close when there is no upstream UDP data

</ProtoField>

<ProtoField name="upLinkOnlyTimeout" type="int32">

After downstream ends, close if there is no upstream data

</ProtoField>

<ProtoField name="downLinkOnlyTimeout" type="int32">

After upstream ends, close if there is no downstream data

</ProtoField>

<ProtoField name="defaultBufferSize" type="int32">

Default per-connection buffer

</ProtoField>

<ProtoField name="userPolicyMap" type="map&lt;uint32, UserPolicy&gt;">

Overrides by `userLevel`

</ProtoField>

## UserPolicy

<ProtoField name="bufferSize">

Buffer size for users at this level

</ProtoField>

User levels come from each account's `userLevel` in [UserConfig](/docs/vx-core/configuration/users).

## Example

```json
{
  "policy": {
    "handshakeTimeout": 4,
    "connectionIdleTimeout": 300,
    "udpIdleTimeout": 60,
    "userPolicyMap": {
      "0": { "bufferSize": 4096 }
    }
  }
}
```
