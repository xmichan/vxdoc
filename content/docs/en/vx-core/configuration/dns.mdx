DNS is configured in `ServerConfig.dns` (`DnsConfig`). Schema: [`protos/proto/vx/dns/dns.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/dns/dns.proto).

## DnsConfig

<ProtoField name="records" type="Record[]">

Static domain → IP mappings

</ProtoField>

<ProtoField name="recordStrings" type="string[]">

Alternate record encoding

</ProtoField>

<ProtoField name="dnsServers" type="DnsServerConfig[]">

Named DNS upstreams

</ProtoField>

<ProtoField name="internalResolver" type="Resolver">

Resolver used when **dialing** outbounds

</ProtoField>

<ProtoField name="requestDomainResolver" type="Resolver">

Resolver for **incoming** DNS requests

</ProtoField>

<ProtoField name="concurrentDnsServers" type="ConcurrentDnsServer[]">

Query multiple servers in parallel

</ProtoField>

<ProtoField name="serialDnsServers" type="SerialDnsServer[]">

Try servers one after another

</ProtoField>

<ProtoField name="resolvers" type="Resolver[]">

Additional named resolvers

</ProtoField>

<ProtoField name="dnsHijack" type="DnsHijackConfig">

Hijack rules and fake DNS toggle

</ProtoField>

### Record

<ProtoField name="domain">

Hostname

</ProtoField>

<ProtoField name="ip">

Static answers

</ProtoField>

<ProtoField name="proxiedDomain">

Map this domain to the same IPs as `proxiedDomain`

</ProtoField>

### Resolver

<ProtoField name="dnsServers">

Server names or addresses

</ProtoField>

<ProtoField name="interval">

Wait between tries (serial behavior)

</ProtoField>

<ProtoField name="name">

Resolver name

</ProtoField>

## DnsServerConfig

Each server has a `name` and a `type` oneof:

<ProtoField name="plainDnsServer" type="PlainDnsServer">

UDP DNS (`addresses`, `useDefaultDns`)

</ProtoField>

<ProtoField name="tlsDnsServer" type="TlsDnsServer">

DNS over TLS

</ProtoField>

<ProtoField name="dohDnsServer" type="DohDnsServer">

DNS over HTTPS (`url`)

</ProtoField>

<ProtoField name="quicDnsServer" type="QuicDnsServer">

DNS over QUIC

</ProtoField>

<ProtoField name="fakeDnsServer" type="FakeDnsServer">

Fake-IP pools (`poolConfigs`: `cidr`, `lruSize`)

</ProtoField>

<ProtoField name="goDnsServer" type="GoDnsServer">

Go resolver

</ProtoField>

<ProtoField name="emptyDnsServer" type="EmptyDnsServer">

No-op / placeholder

</ProtoField>

Common fields:

<ProtoField name="clientIp">

EDNS client subnet

</ProtoField>

<ProtoField name="cacheDuration">

Override TTL cache; `0` = use minimum answer TTL

</ProtoField>

<ProtoField name="ipTags">

Drop answers outside these [geo](/docs/vx-core/configuration/geo) IP sets

</ProtoField>

## DnsHijackConfig

<ProtoField name="dnsRules">

`DnsRuleConfig[]` — pick server by domain/tags/type

</ProtoField>

<ProtoField name="enableFakeDns">

Enable fake DNS for hijacked queries

</ProtoField>

### DnsRuleConfig

<ProtoField name="dnsServerName">

Target `DnsServerConfig.name`

</ProtoField>

<ProtoField name="domains, domainTags">

Match query names

</ProtoField>


<ProtoField name="includedTypes">

`A`, `AAAA`, `HTTPS`, …

</ProtoField>

<ProtoField name="ruleName">

Debug label

</ProtoField>
