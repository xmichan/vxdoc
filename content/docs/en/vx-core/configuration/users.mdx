This message is used in `ServerConfig.users` (`UserConfig[]`). It is also used in the `users` field of [inbounds](/docs/vx-core/configuration/inbounds).

Schema definition: [`protos/proto/vx/user/user.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/user/user.proto).

## UserConfig

<ProtoField name="id" type="string">

User identifier (used for routing `usernames`)

</ProtoField>

<ProtoField name="userLevel" type="uint32">

Policy level for [PolicyConfig](/docs/vx-core/configuration/policy) `userPolicyMap`

</ProtoField>

<ProtoField name="secret" type="string">

Password of arbitrary length

</ProtoField>

## Example

```json
{
  "users": [
    {
      "id": "alice",
      "userLevel": 0,
      "secret": "00000000-0000-0000-0000-000000000001"
    }
  ],
  "inbounds": [
    {
      "tag": "vless",
      "ports": [443],
      "users": [
        {
          "id": "alice",
          "userLevel": 0,
          "secret": "00000000-0000-0000-0000-000000000001"
        }
      ],
      "protocol": {
        "@type": "type.googleapis.com/vx.proxy.vless.VlessServerConfig"
      }
    }
  ]
}
```

Inbound-level `users` are added to all proxy handlers on that inbound. Global `users` are added to all proxy handlers on every inbound.
