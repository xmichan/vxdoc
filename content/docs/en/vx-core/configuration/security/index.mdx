---
title: Security
description: TLS and REALITY on TransportConfig
---

The security layer encrypts or disguises connections beneath the wire protocol. Configure it on [`TransportConfig`](/docs/vx-core/configuration/transport) via `tls` or `reality` (oneof with the transport protocol).

```json
{
  "transport": {
    "tcp": {},
    "reality": {
      "dest": "www.microsoft.com:443",
      "serverNames": ["www.example.com"],
      "privateKey": "...",
      "shortIds": ["abcd1234"]
    }
  }
}
```

Hysteria2 uses an inline `tlsConfig` inside the [protocol message](/docs/vx-core/configuration/protocols/hysteria), not `TransportConfig`.
