Protos:

- [`tls.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/transport/security/tls/tls.proto) — `TlsConfig`
- [`certificate.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/transport/security/tls/certificate.proto) — `Certificate`

Set on `TransportConfig.tls`, `MultiProxyInboundConfig.securityConfigs[].tls`, Hysteria2 `tlsConfig`, and SplitHTTP `downloadSettings.tls`.

## TlsConfig

<ProtoField name="certificates">

Server/client cert chain (`Certificate[]`)

</ProtoField>

<ProtoField name="rootCas">

Custom root CA PEM blobs

</ProtoField>

<ProtoField name="issueCas">

CAs used to issue certs to peers

</ProtoField>

<ProtoField name="serverName">

SNI; default = destination domain when dialing

</ProtoField>

<ProtoField name="disableSystemRoot">

Do not use system root CAs

</ProtoField>

<ProtoField name="allowInsecure">

Skip certificate verification (client)

</ProtoField>

<ProtoField name="nextProtocol">

ALPN list

</ProtoField>

<ProtoField name="enableSessionResumption">

TLS session tickets / resumption

</ProtoField>

<ProtoField name="pinnedPeerCertificateChainSha256">

Pin peer cert chain hashes

</ProtoField>

<ProtoField name="verifyClientCertificate">

Require valid client cert (server)

</ProtoField>

<ProtoField name="imitate">

uTLS client fingerprint name

</ProtoField>

<ProtoField name="noSNI">

Do not send SNI (uTLS)

</ProtoField>

<ProtoField name="forceAlpn">

`TRANSPORT_PREFERENCE_TAKE_PRIORITY`, `NO_ALPN`, `UTLS_PRESET`

</ProtoField>

<ProtoField name="masterKeyLog">

NSS key log path (debug)

</ProtoField>

<ProtoField name="echKey">

Server ECH key

</ProtoField>

<ProtoField name="echConfig">

Client ECH config blob

</ProtoField>

<ProtoField name="enableEch">

Client: enable ECH

</ProtoField>

### ForceALPN

<ProtoField name="TRANSPORT_PREFERENCE_TAKE_PRIORITY">

User ALPN if set, else transport default

</ProtoField>

<ProtoField name="NO_ALPN">

Do not send ALPN extension

</ProtoField>

<ProtoField name="UTLS_PRESET">

Use uTLS preset ALPN

</ProtoField>

## Certificate

<ProtoField name="certificate">

PEM cert bytes

</ProtoField>

<ProtoField name="key">

PEM private key bytes

</ProtoField>

<ProtoField name="certificateFilepath">

Path to cert file

</ProtoField>

<ProtoField name="keyFilepath">

Path to key file

</ProtoField>

```json
{
  "transport": {
    "tcp": {},
    "tls": {
      "serverName": "example.com",
      "certificates": [
        {
          "certificateFilepath": "/etc/vx/fullchain.pem",
          "keyFilepath": "/etc/vx/privkey.pem"
        }
      ],
      "nextProtocol": ["h2", "http/1.1"]
    }
  }
}
```
