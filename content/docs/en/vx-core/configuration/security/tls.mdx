Protos:

- [`tls.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/transport/security/tls/tls.proto) — `TlsConfig`
- [`certificate.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/transport/security/tls/certificate.proto) — `Certificate`

Set on `TransportConfig.tls`, `MultiProxyInboundConfig.securityConfigs[].tls`, Hysteria2 `tlsConfig`, and SplitHTTP `downloadSettings.tls`.

**Mutually exclusive** with `reality` (only one per transport block).

## TlsConfig

<ProtoField name="certificates" type="Certificate[]">

Server/client certificate chain

</ProtoField>

<ProtoField name="rootCas" type="bytes[]">

Custom root CA PEM (each entry is a PEM byte blob)

</ProtoField>

<ProtoField name="issueCas" type="Certificate[]">

CAs used to issue certificates to peers

</ProtoField>

<ProtoField name="serverName" type="string">

SNI; defaults to the target domain when dialing

</ProtoField>

<ProtoField name="disableSystemRoot" type="bool">

Do not use system root CAs

</ProtoField>

<ProtoField name="allowInsecure" type="bool">

Skip certificate verification (**client**)

</ProtoField>

<ProtoField name="nextProtocol" type="string[]">

ALPN list (e.g. `h2`, `http/1.1`)

</ProtoField>

<ProtoField name="enableSessionResumption" type="bool">

Enable TLS session tickets / resumption

</ProtoField>

<ProtoField name="pinnedPeerCertificateChainSha256" type="bytes[]">

Pinned peer certificate chain SHA-256 hashes (each entry is 32 bytes)

</ProtoField>

<ProtoField name="verifyClientCertificate" type="bool">

Require a valid client certificate (**server**)

</ProtoField>

<ProtoField name="imitate" type="string">

uTLS client fingerprint name (e.g. `chrome`)

</ProtoField>

<ProtoField name="noSNI" type="bool">

Do not send SNI (uTLS)

</ProtoField>

<ProtoField name="forceAlpn" type="ForceALPN">

ALPN behavior; see [ForceALPN](#forcealpn)

</ProtoField>

<ProtoField name="masterKeyLog" type="string">

NSS key log path (debugging)

</ProtoField>

<ProtoField name="echKey" type="bytes">

Server ECH key

</ProtoField>

<ProtoField name="echConfig" type="bytes">

Client ECH config blob

</ProtoField>

<ProtoField name="enableEch" type="bool">

Client: enable ECH

</ProtoField>

### ForceALPN

<ProtoField name="TRANSPORT_PREFERENCE_TAKE_PRIORITY" type="0">

Use user-configured ALPN if set; otherwise transport default

</ProtoField>

<ProtoField name="NO_ALPN" type="1">

Do not send ALPN extension

</ProtoField>

<ProtoField name="UTLS_PRESET" type="2">

Use uTLS preset ALPN

</ProtoField>

## Certificate

Certificates and private keys can be inline PEM bytes or loaded from file paths (paths take precedence over inline).

<ProtoField name="certificate" type="bytes">

PEM certificate bytes

</ProtoField>

<ProtoField name="key" type="bytes">

PEM private key bytes

</ProtoField>

<ProtoField name="certificateFilepath" type="string">

Certificate file path

</ProtoField>

<ProtoField name="keyFilepath" type="string">

Private key file path

</ProtoField>

```json
{
  "transport": {
    "tcp": {},
    "tls": {
      "serverName": "example.com",
      "certificates": [
        {
          "certificateFilepath": "/etc/vx/fullchain.pem",
          "keyFilepath": "/etc/vx/privkey.pem"
        }
      ],
      "nextProtocol": ["h2", "http/1.1"]
    }
  }
}
```
