## VlessClientConfig

<ProtoField name="id" type="string">

Account UUID

</ProtoField>

<ProtoField name="flow" type="string">

Flow control, for example `xtls-rprx-vision`

</ProtoField>

<ProtoField name="encryption" type="string">

Client only; currently `none`

</ProtoField>

```json
{
  "@type": "type.googleapis.com/vx.proxy.vless.VlessClientConfig",
  "id": "66ad4540-b58c-4ad2-9926-ea63445a9b57",
  "flow": "xtls-rprx-vision",
  "encryption": "none"
}
```

Vision flow control is typically used with [REALITY](/docs/vx-core/configuration/security/reality) or [TLS](/docs/vx-core/configuration/security/tls) on the transport.
