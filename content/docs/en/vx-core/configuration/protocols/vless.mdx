## VlessServerConfig

<ProtoField name="users" type="UserConfig[]">

Allowed users; `id` is UUID, `secret` optional

</ProtoField>

```json
{
  "@type": "type.googleapis.com/vx.proxy.vless.VlessServerConfig",
  "users": [
    { "id": "66ad4540-b58c-4ad2-9926-ea63445a9b57", "userLevel": 0 }
  ]
}
```

## VlessClientConfig

<ProtoField name="id" type="string">

Account UUID

</ProtoField>

<ProtoField name="flow" type="string">

Flow control, e.g. `xtls-rprx-vision`

</ProtoField>

<ProtoField name="encryption" type="string">

Client-only; currently `none`

</ProtoField>

```json
{
  "@type": "type.googleapis.com/vx.proxy.vless.VlessClientConfig",
  "id": "66ad4540-b58c-4ad2-9926-ea63445a9b57",
  "flow": "xtls-rprx-vision",
  "encryption": "none"
}
```

Vision flow typically pairs with [REALITY](/docs/vx-core/configuration/security/reality) or [TLS](/docs/vx-core/configuration/security/tls) on the transport.
