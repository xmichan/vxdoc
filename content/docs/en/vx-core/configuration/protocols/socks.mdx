## AuthType

<ProtoField name="NO_AUTH">

Anonymous

</ProtoField>

<ProtoField name="PASSWORD">

Username/password

</ProtoField>

## SocksServerConfig

<ProtoField name="authType" type="AuthType">

Authentication mode

</ProtoField>

<ProtoField name="accounts" type="UserConfig[]">

Users when `PASSWORD`

</ProtoField>

<ProtoField name="address" type="string">

BND.ADDR in SOCKS reply

</ProtoField>

<ProtoField name="udpEnabled" type="bool">

Enable UDP associate

</ProtoField>

## SocksClientConfig

<ProtoField name="name" type="string">

Username

</ProtoField>

<ProtoField name="password" type="string">

Password

</ProtoField>

<ProtoField name="delayAuthWrite" type="bool">

Delay auth write on connection

</ProtoField>

```json
{
  "@type": "type.googleapis.com/vx.proxy.socks.SocksServerConfig",
  "authType": "PASSWORD",
  "udpEnabled": true,
  "accounts": [{ "id": "u1", "secret": "pass" }]
}
```
