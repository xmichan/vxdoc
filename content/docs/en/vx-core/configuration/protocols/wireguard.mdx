---
title: WireGuard
description: DeviceConfig and PeerConfig
---

Proto: [`protos/proto/vx/proxy/wireguard/config.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/proxy/wireguard/config.proto)

WireGuard is configured as an outbound `DeviceConfig` (no separate `*ServerConfig` in this proto).

## DeviceConfig

<ProtoField name="secretKey" type="string">

Local private key

</ProtoField>

<ProtoField name="endpoint" type="string[]">

Endpoint host(s)

</ProtoField>

<ProtoField name="peers" type="PeerConfig[]">

Remote peers

</ProtoField>

<ProtoField name="mtu" type="int32">

Interface MTU

</ProtoField>

<ProtoField name="numWorkers" type="int32">

Worker count

</ProtoField>

<ProtoField name="reserved" type="bytes">

WireGuard reserved bytes (3)

</ProtoField>

<ProtoField name="isClient" type="bool">

Client mode

</ProtoField>

<ProtoField name="noKernelTun" type="bool">

Userspace tun only

</ProtoField>

## PeerConfig

<ProtoField name="publicKey">

Peer public key

</ProtoField>

<ProtoField name="preSharedKey">

Optional PSK

</ProtoField>

<ProtoField name="endpoint">

Peer endpoint `host:port`

</ProtoField>

<ProtoField name="keepAlive">

Persistent keepalive (seconds)

</ProtoField>

<ProtoField name="allowedIps">

Allowed IP CIDRs for this peer

</ProtoField>

```json
{
  "@type": "type.googleapis.com/vx.proxy.wireguard.DeviceConfig",
  "secretKey": "...",
  "isClient": true,
  "peers": [
    {
      "publicKey": "...",
      "endpoint": "vpn.example.com:51820",
      "allowedIps": ["0.0.0.0/0", "::/0"]
    }
  ]
}
```
