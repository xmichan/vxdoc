Proto: [`protos/proto/vx/proxy/wireguard/config.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/proxy/wireguard/config.proto)

WireGuard is used only as an **outbound** `DeviceConfig` (this proto has no `*ServerConfig`).

## DeviceConfig

<ProtoField name="secretKey" type="string">

Local interface private key (WireGuard key format)

</ProtoField>

<ProtoField name="endpoint" type="string[]">

Device-level endpoint host list (optional)

</ProtoField>

<ProtoField name="peers" type="PeerConfig[]">

Remote peers; see [PeerConfig](#peerconfig)

</ProtoField>

<ProtoField name="mtu" type="int32">

TUN interface MTU

</ProtoField>

<ProtoField name="numWorkers" type="int32">

Number of encryption worker threads

</ProtoField>

<ProtoField name="reserved" type="bytes">

WireGuard protocol reserved bytes (3 bytes, used to bypass blocking)

</ProtoField>

<ProtoField name="noKernelTun" type="bool">

When `true`, use userspace TUN only; do not use kernel WireGuard

</ProtoField>

```json
{
  "@type": "type.googleapis.com/vx.proxy.wireguard.DeviceConfig",
  "secretKey": "...",
  "isClient": true,
  "peers": [
    {
      "publicKey": "...",
      "endpoint": "vpn.example.com:51820",
      "allowedIps": ["0.0.0.0/0", "::/0"]
    }
  ]
}
```

## PeerConfig

<ProtoField name="publicKey" type="string">

Peer public key

</ProtoField>

<ProtoField name="preSharedKey" type="string">

Optional pre-shared key (PSK)

</ProtoField>

<ProtoField name="endpoint" type="string">

Peer endpoint `host:port`

</ProtoField>

<ProtoField name="keepAlive" type="uint32">

Persistent keepalive interval (**seconds**)

</ProtoField>

<ProtoField name="allowedIps" type="string[]">

List of IP CIDRs routed through this peer

</ProtoField>
