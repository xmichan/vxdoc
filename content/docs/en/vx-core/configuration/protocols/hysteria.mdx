Proto: [`protos/proto/vx/proxy/hysteria/hysteria.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/proxy/hysteria/hysteria.proto)

Hysteria2 runs over QUIC. TLS is configured inside the protocol via `tlsConfig` ([TlsConfig](/docs/vx-core/configuration/security/tls)).

## Hysteria2ServerConfig

<ProtoField name="users">

`UserConfig[]` — auth string in `secret`

</ProtoField>

<ProtoField name="obfs">

`ObfsConfig` (Salamander)

</ProtoField>

<ProtoField name="bandwidth">

`maxTx` / `maxRx` caps

</ProtoField>

<ProtoField name="quic">

QUIC window and timeout settings

</ProtoField>

<ProtoField name="ignoreClientBandwidth">

Ignore client bandwidth hints

</ProtoField>

<ProtoField name="tlsConfig">

Server TLS

</ProtoField>

<ProtoField name="addresses">

Listen / announce addresses

</ProtoField>

## Hysteria2ClientConfig

<ProtoField name="auth">

Auth password

</ProtoField>

<ProtoField name="tlsConfig">

Client TLS (SNI, pins, ECH, …)

</ProtoField>

<ProtoField name="quic">

QUIC tuning

</ProtoField>

<ProtoField name="fastOpen">

QUIC fast open

</ProtoField>

<ProtoField name="bandwidth">

Client upload/download limits

</ProtoField>

<ProtoField name="obfs">

Obfuscation

</ProtoField>

### QuicConfig (shared)

<ProtoField name="initialStreamReceiveWindow, maxStreamReceiveWindow, …">

Stream windows (MB or `*Bytes` variants)

</ProtoField>

<ProtoField name="initialConnectionReceiveWindow, maxConnectionReceiveWindow, …">

Connection windows

</ProtoField>

<ProtoField name="maxIdleTimeout, keepAlivePeriod">

QUIC timeouts

</ProtoField>


<ProtoField name="disablePathMtuDiscovery">

Disable PMTUD

</ProtoField>

<ProtoField name="maxIncomingStreams">

Server-only stream limit

</ProtoField>

### ObfsConfig

<ProtoField name="salamander">

`SalamanderConfig` with `password`

</ProtoField>

### BandwidthConfig

<ProtoField name="maxTx">

Upload cap (client: upload)

</ProtoField>

<ProtoField name="maxRx">

Download cap (client: download)

</ProtoField>

```json
{
  "@type": "type.googleapis.com/vx.proxy.hysteria.Hysteria2ServerConfig",
  "users": [{ "secret": "auth-password" }],
  "tlsConfig": {
    "certificates": [{ "certificateFilepath": "/path/cert.pem", "keyFilepath": "/path/key.pem" }]
  }
}
```
