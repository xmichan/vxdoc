Geo data sets are defined in `ServerConfig.geo` (`GeoConfig`). Schema: [`protos/proto/vx/geo/geo.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/geo/geo.proto).

Router [rules](/docs/vx-core/configuration/router) and [DNS](/docs/vx-core/configuration/dns) refer to sets by **name** via `domainTags`, `dstIpTags`, `srcIpTags`, and `geoDomains`.

## GeoConfig

<ProtoField name="domainSets" type="DomainSetConfig[]">

Named groups of domain set tags

</ProtoField>

<ProtoField name="greatDomainSets" type="GreatDomainSetConfig[]">

Composed domain sets (`inNames`, `exNames`, opposites)

</ProtoField>

<ProtoField name="atomicDomainSets" type="AtomicDomainSetConfig[]">

Concrete domain lists or geosite files

</ProtoField>

<ProtoField name="greatIpSets" type="GreatIPSetConfig[]">

Composed IP sets

</ProtoField>

<ProtoField name="atomicIpSets" type="AtomicIPSetConfig[]">

CIDR lists or geoip files

</ProtoField>

<ProtoField name="appSets" type="AppSetConfig[]">

Mobile app id groupings

</ProtoField>

Names must be unique within each category (no duplicate names across `greatDomainSets` and `atomicDomainSets`, and similarly for IP sets).

## Domain

A single domain matching rule. Defined in [`protos/proto/vx/common/geo/geo.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/common/geo/geo.proto).

Used in [router](/docs/vx-core/configuration/router) rule `geoDomains` and [AtomicDomainSetConfig](#atomicdomainsetconfig) `domains`.

<ProtoField name="type" type="Domain.Type">

How to match:

- `Plain` — substring (keyword) match
- `Regex` — regular expression match
- `RootDomain` — root domain and subdomains (suffix match)
- `Full` — exact hostname match

</ProtoField>

<ProtoField name="value" type="string">

Domain or pattern to match

</ProtoField>

<ProtoField name="attribute" type="Domain.Attribute[]">

Optional attributes for filtering (e.g. geosite)

</ProtoField>

### Domain.Attribute

<ProtoField name="key" type="string">

Attribute name

</ProtoField>

<ProtoField name="boolValue, intValue" type="bool · int64">

Attribute value (set one)

</ProtoField>
