Outbound handlers are listed in `ServerConfig.outbounds`. Schema: [`protos/proto/vx/outbound/outbound.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/outbound/outbound.proto).

Each handler has a unique `tag` used by [router](/docs/vx-core/configuration/router) rules (`outboundTag`) or as a chain target.

## OutboundHandlerConfig

<ProtoField name="tag" type="string">

Handler name for routing

</ProtoField>

<ProtoField name="transport" type="TransportConfig">

Client transport (TLS, WebSocket, …)

</ProtoField>

<ProtoField name="address" type="string">

Remote host or IP

</ProtoField>

<ProtoField name="port" type="uint32">

Remote port

</ProtoField>

<ProtoField name="ports" type="PortRange[]">

Multiple port ranges

</ProtoField>

<ProtoField name="protocol" type="Any">

Proxy client config (Freedom, Blackhole, VMess, …)

</ProtoField>

<ProtoField name="enableMux" type="bool">

Enable connection mux

</ProtoField>

<ProtoField name="muxConfig" type="MuxConfig">

`maxConnection`, `maxConcurrency`

</ProtoField>

<ProtoField name="uot" type="bool">

UDP over TCP

</ProtoField>

<ProtoField name="domainStrategy" type="enum">

How to resolve domains when dialing (`PreferIPv4`, `PreferIPv6`, `IPv4Only`, `IPv6Only`, `Speed`)

</ProtoField>

<ProtoField name="random" type="RandomPortSelectStrategy">

Use all ports in `ports` at once

</ProtoField>

<ProtoField name="one" type="OnePortSelectStrategy">

Rotate a single port (`interval` or `minInterval` / `maxInterval`)

</ProtoField>

### Direct (freedom) outbound

Required for a minimal server that forwards traffic without an upstream proxy:

```json
{
  "tag": "direct",
  "protocol": {
    "@type": "type.googleapis.com/vx.proxy.freedom.FreedomConfig"
  }
}
```

### Block outbound

```json
{
  "tag": "block",
  "protocol": {
    "@type": "type.googleapis.com/vx.proxy.blackhole.BlackholeConfig"
  }
}
```

Proxy client configs: [Proxy protocols](/docs/vx-core/configuration/protocols) (`*ClientConfig` messages). Wrap with [Transport](/docs/vx-core/configuration/transport) and [Security](/docs/vx-core/configuration/security) as needed.

## OutboundConfig (client / advanced)

`OutboundConfig` in the same proto file is used in richer client setups (handler lists, chains, stats). Server `ServerConfig` uses the flat `outbounds` repeated field of `OutboundHandlerConfig` only.

<ProtoField name="handlers">

`HandlerConfig[]` — single outbound or `ChainHandlerConfig`

</ProtoField>

<ProtoField name="hysteriaRejectQuic">

Reject QUIC for Hysteria

</ProtoField>

<ProtoField name="handlerLinkStats, handlerMeter, totalCounter">

Stats and metering

</ProtoField>
