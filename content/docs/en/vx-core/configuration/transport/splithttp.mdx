Proto: [`protos/proto/vx/transport/protocols/splithttp/config.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/transport/protocols/splithttp/config.proto)

Split HTTP / XHTTP transport. Set on `TransportConfig.splithttp`.

## SplitHttpConfig

<ProtoField name="host">

Host header

</ProtoField>

<ProtoField name="path">

Request path

</ProtoField>

<ProtoField name="mode">

Operating mode string

</ProtoField>

<ProtoField name="headers">

Extra headers map

</ProtoField>

<ProtoField name="xPaddingBytes">

`RangeConfig` padding range

</ProtoField>

<ProtoField name="noGRPCHeader">

Omit gRPC-style headers

</ProtoField>

<ProtoField name="noSSEHeader">

Server: omit SSE headers

</ProtoField>

<ProtoField name="scMaxEachPostBytes">

Max bytes per POST (`RangeConfig`)

</ProtoField>

<ProtoField name="scMinPostsIntervalMs">

Min interval between POSTs

</ProtoField>

<ProtoField name="scMaxBufferedPosts">

Server: max buffered posts

</ProtoField>

<ProtoField name="scStreamUpServerSecs">

Server stream-up timeout range

</ProtoField>

<ProtoField name="xmux">

`XmuxConfig` — mux concurrency/connection limits

</ProtoField>

<ProtoField name="downloadSettings">

Separate `DownConfig` for download path

</ProtoField>

### RangeConfig

<ProtoField name="from, to">

Inclusive int32 range

</ProtoField>


### XmuxConfig

<ProtoField name="maxConcurrency, maxConnections, cMaxReuseTimes, hMaxRequestTimes, hMaxReusableSecs" type="RangeConfig">

Limits

</ProtoField>


<ProtoField name="hKeepAlivePeriod">

Keep-alive period

</ProtoField>

### DownConfig

<ProtoField name="address, port">

Download endpoint

</ProtoField>


<ProtoField name="xhttpConfig" type="SplitHttpConfig">

Nested config

</ProtoField>

<ProtoField name="tls, reality">

Security for download leg (`TlsConfig` or `RealityConfig` oneof)

</ProtoField>


```json
{
  "transport": {
    "splithttp": {
      "path": "/xhttp",
      "host": "example.com",
      "mode": "auto"
    },
    "tls": { "serverName": "example.com" }
  }
}
```
