UDP-based KCP transport. Set on `TransportConfig.kcp`.

## KcpConfig

<ProtoField name="mtu" type="uint32">

MTU

</ProtoField>

<ProtoField name="tti" type="uint32">

Transmission time interval

</ProtoField>

<ProtoField name="uplinkCapacity" type="uint32">

Uplink capacity (deprecated style tuning)

</ProtoField>

<ProtoField name="downlinkCapacity" type="uint32">

Downlink capacity

</ProtoField>

<ProtoField name="congestion" type="bool">

Enable congestion control

</ProtoField>

<ProtoField name="writeBuffer" type="uint32">

Write buffer size

</ProtoField>

<ProtoField name="readBuffer" type="uint32">

Read buffer size

</ProtoField>

<ProtoField name="headerConfig" type="Any">

Packet header disguise (same family as [TCP headers](/docs/vx-core/configuration/transport/tcp))

</ProtoField>

<ProtoField name="seed" type="string">

Obfuscation seed

</ProtoField>

```json
{
  "transport": {
    "kcp": {
      "mtu": 1350,
      "tti": 50,
      "uplinkCapacity": 12,
      "downlinkCapacity": 100
    }
  }
}
```
