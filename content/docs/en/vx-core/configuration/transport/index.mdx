Transport settings wrap proxy protocols on [inbounds](/docs/vx-core/configuration/inbounds) and [outbounds](/docs/vx-core/configuration/outbounds) via `transport: { ... }`.

Root message: [`TransportConfig`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/transport/transport.proto) in `protos/proto/vx/transport/transport.proto`.

## TransportConfig

<ProtoField name="socket" type="SocketConfig">

Marks, TFO, bind, buffers

</ProtoField>

<ProtoField name="tcp, kcp, websocket, http, grpc, httpupgrade, splithttp">

Wire protocol (oneof)

</ProtoField>

<ProtoField name="tls, reality">

Security layer (oneof); see [Security](/docs/vx-core/configuration/security)

</ProtoField>

<ProtoField name="transportProtocol, securityProtocol, Any">

`Any` escape hatch for extended types

</ProtoField>


Only one **protocol** and one **security** field should be set per config.

## Example (VLESS + WebSocket + TLS)

```json
{
  "tag": "vless-ws",
  "ports": [443],
  "transport": {
    "websocket": { "path": "/ws", "host": "example.com" },
    "tls": {
      "serverName": "example.com",
      "certificates": [
        { "certificateFilepath": "/etc/vx/cert.pem", "keyFilepath": "/etc/vx/key.pem" }
      ]
    }
  },
  "protocol": {
    "@type": "type.googleapis.com/vx.proxy.vless.VlessServerConfig",
    "users": [{ "id": "uuid" }]
  }
}
```

## Multi-inbound transport matrix

On `MultiProxyInboundConfig`, transport protocols are selected per ALPN/SNI/path in `transportProtocols[]` instead of a single `TransportConfig`. Security blocks work the same way in `securityConfigs[]`. See [Inbounds](/docs/vx-core/configuration/inbounds).
