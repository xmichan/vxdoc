Transport settings wrap proxy protocols via `transport: { ... }` on [inbounds](/docs/vx-core/configuration/inbounds) and [outbounds](/docs/vx-core/configuration/outbounds).

Root message: [`TransportConfig`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/transport/transport.proto), in `protos/proto/vx/transport/transport.proto`.

## TransportConfig

<ProtoField name="socket" type="SocketConfig">

Socket options (mark, TFO, bind, buffers, etc.). See [Socket](/docs/vx-core/configuration/transport/socket).

</ProtoField>

### Link protocols (oneof)

`tcp`, `kcp`, `websocket`, `http`, `grpc`, `httpupgrade`, and `splithttp` are mutually exclusive; each `TransportConfig` may set only one.

<ProtoField name="tcp" type="TcpConfig">

Plain TCP transport. See [TCP](/docs/vx-core/configuration/transport/tcp).

</ProtoField>

<ProtoField name="kcp" type="KcpConfig">

UDP-based KCP transport. See [KCP](/docs/vx-core/configuration/transport/kcp).

</ProtoField>

<ProtoField name="websocket" type="WebsocketConfig">

WebSocket transport. See [WebSocket](/docs/vx-core/configuration/transport/websocket).

</ProtoField>

<ProtoField name="http" type="HttpConfig">

HTTP/2 transport camouflage. See [HTTP transport](/docs/vx-core/configuration/transport/http).

</ProtoField>

<ProtoField name="grpc" type="GrpcConfig">

gRPC transport. See [gRPC](/docs/vx-core/configuration/transport/grpc).

</ProtoField>

<ProtoField name="httpupgrade" type="HttpUpgradeConfig">

HTTP Upgrade transport. See [HTTPUpgrade](/docs/vx-core/configuration/transport/httpupgrade).

</ProtoField>

<ProtoField name="splithttp" type="SplitHttpConfig">

Split HTTP (XHTTP) transport. See [SplitHTTP](/docs/vx-core/configuration/transport/splithttp).

</ProtoField>

### Security layer (oneof)

`tls` and `reality` are mutually exclusive. See [Security](/docs/vx-core/configuration/security).

<ProtoField name="tls" type="TlsConfig">

TLS certificates, SNI, uTLS, ECH

</ProtoField>

<ProtoField name="reality" type="RealityConfig">

REALITY camouflage

</ProtoField>

### Extensions

<ProtoField name="transportProtocol" type="Any">

`Any` escape hatch for custom transport protocols

</ProtoField>

<ProtoField name="securityProtocol" type="Any">

`Any` escape hatch for custom security protocols

</ProtoField>

Each configuration should set at most one **link protocol** and one **security** field (or neither).

## Example (VLESS + WebSocket + TLS)

```json
{
  "tag": "vless-ws",
  "ports": [443],
  "transport": {
    "websocket": { "path": "/ws", "host": "example.com" },
    "tls": {
      "serverName": "example.com",
      "certificates": [
        { "certificateFilepath": "/etc/vx/cert.pem", "keyFilepath": "/etc/vx/key.pem" }
      ]
    }
  },
  "protocol": {
    "@type": "type.googleapis.com/vx.proxy.vless.VlessServerConfig",
    "users": [{ "id": "uuid" }]
  }
}
```

## Multi-inbound transport matrix

On `MultiProxyInboundConfig`, transport protocols are selected via `transportProtocols[]` by ALPN/SNI/path, rather than a single `TransportConfig`. Security blocks in `securityConfigs[]` work the same way. See [Inbounds](/docs/vx-core/configuration/inbounds).
