## WebsocketConfig

<ProtoField name="host" type="string">

Host header / authority

</ProtoField>

<ProtoField name="path" type="string">

URL path; empty = `/`

</ProtoField>

<ProtoField name="header" type="Header[]">

Extra headers (`key`, `value`)

</ProtoField>

<ProtoField name="maxEarlyData" type="int32">

Max early data bytes

</ProtoField>

<ProtoField name="useBrowserForwarding" type="bool">

Browser forwarding mode

</ProtoField>

<ProtoField name="earlyDataHeaderName" type="string">

Header carrying early data

</ProtoField>

```json
{
  "transport": {
    "websocket": {
      "path": "/ray",
      "host": "example.com"
    },
    "tls": { "serverName": "example.com" }
  }
}
```

Also embedded in [HTTPUpgrade](/docs/vx-core/configuration/transport/httpupgrade).
