Outbound dialing defaults are set in `ServerConfig.dialerFactory` (`DialerFactoryConfig`). Schema: [`protos/proto/vx/dialerfactory/dialerfactory.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/dialerfactory/dialerfactory.proto).

## DialerFactoryConfig

<ProtoField name="dialTimeout" type="uint32">

Timeout for establishing outbound connections (seconds)

</ProtoField>

<ProtoField name="shouldBindDevice" type="bool">

Bind sockets to the default network interface

</ProtoField>

<ProtoField name="useInternalResolver" type="bool">

Use [DNS](/docs/vx-core/configuration/dns) `internalResolver` when resolving domains on dial

</ProtoField>

## Example

```json
{
  "dialerFactory": {
    "dialTimeout": 10,
    "shouldBindDevice": false,
    "useInternalResolver": true
  }
}
```
