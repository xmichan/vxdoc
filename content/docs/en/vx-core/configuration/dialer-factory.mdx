All outbounds are created by this factory.
Schema definition: [`protos/proto/vx/dialerfactory/dialerfactory.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/dialerfactory/dialerfactory.proto).

Used in `ServerConfig.dialerFactory`.

## DialerFactoryConfig

<ProtoField name="dialTimeout" type="uint32">

Connection timeout (seconds)

</ProtoField>

<ProtoField name="shouldBindDevice" type="bool">

Bind the socket to the default physical network NIC

</ProtoField>

<ProtoField name="resolveDomain" type="bool">

Use the [internal DNS resolver](/docs/vx-core/configuration/dns) `internalResolver` when resolving domains during dialing

</ProtoField>

## Example

```json
{
  "dialerFactory": {
    "dialTimeout": 10,
    "shouldBindDevice": false,
    "resolveDomain": true
  }
}
```
