Logging is configured in `ServerConfig.log` (`LoggerConfig`). Schema definition: [`protos/proto/vx/log/logger.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/log/logger.proto).

## LoggerConfig

<ProtoField name="logLevel" type="Level">

Minimum level: `DEBUG`, `INFO`, `WARN`, `ERROR`, `FATAL`, `DISABLED`

</ProtoField>

<ProtoField name="filePath" type="string">

Log file path

</ProtoField>

<ProtoField name="logFileDir" type="string">

When `filePath` is empty, write timestamped files in this directory (`2006-01-02T15:04:05.txt`)

</ProtoField>

<ProtoField name="consoleWriter" type="bool">

Human-readable console output

</ProtoField>

<ProtoField name="showColor" type="bool">

Colored logs (with console output)

</ProtoField>

<ProtoField name="showCaller" type="bool">

Include caller location

</ProtoField>

<ProtoField name="redact" type="bool">

Redact domains and IPs in log lines

</ProtoField>

## Example

```json
{
  "log": {
    "logLevel": "INFO",
    "filePath": "/var/log/vx/vx.log",
    "redact": false
  }
}
```
