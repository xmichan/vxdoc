Inbound settings live in `ServerConfig.inbounds` and `ServerConfig.multiInbounds`. Schema: [`protos/proto/vx/inbound/inbound.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/inbound/inbound.proto).

## ProxyInboundConfig

One listener per inbound. Use when each port runs a single proxy protocol (optionally with a shared `transport` layer).

<ProtoField name="tag" type="string">

Name referenced by [router](/docs/vx-core/configuration/router) `inboundTags`

</ProtoField>

<ProtoField name="address" type="string">

Listen address; empty = all interfaces

</ProtoField>

<ProtoField name="port" type="uint32">

Single port (combined with `ports` if both set)

</ProtoField>

<ProtoField name="ports" type="uint32[]">

Ports to listen on

</ProtoField>

<ProtoField name="transport" type="TransportConfig">

TLS, REALITY, WebSocket, gRPC, etc.

</ProtoField>

<ProtoField name="protocol" type="Any">

One proxy server config (VMess, VLESS, Trojan, …)

</ProtoField>

<ProtoField name="protocols" type="Any[]">

Multiple protocols on the same listener

</ProtoField>

<ProtoField name="users" type="UserConfig[]">

Users for this inbound (see [Users](/docs/vx-core/configuration/users))

</ProtoField>

Example:

```json
{
  "tag": "vmess",
  "ports": [10000],
  "protocol": {
    "@type": "type.googleapis.com/vx.proxy.vmess.VmessServerConfig",
    "secureEncryptionOnly": true
  }
}
```

Protocol `@type` values are documented under [Proxy protocols](/docs/vx-core/configuration/protocols). Transport and TLS/REALITY: [Transport](/docs/vx-core/configuration/transport), [Security](/docs/vx-core/configuration/security).

## MultiProxyInboundConfig

Use when one listener must accept **several transports and security profiles** (typical multi-protocol port behind TLS or REALITY).

<ProtoField name="tag" type="string">

Inbound tag for routing

</ProtoField>

<ProtoField name="address" type="string">

Listen address; empty = all interfaces

</ProtoField>

<ProtoField name="ports" type="uint32[]">

Listen ports

</ProtoField>

<ProtoField name="protocols" type="Any[]">

Proxy protocol configs (same `Any` types as above)

</ProtoField>

<ProtoField name="securityConfigs" type="Security[]">

TLS or REALITY per SNI/domain/regex

</ProtoField>

<ProtoField name="transportProtocols" type="Protocol[]">

WebSocket, HTTP, gRPC, TCP, SplitHTTP, HTTPUpgrade

</ProtoField>

<ProtoField name="socket" type="SocketConfig">

Socket-level options

</ProtoField>

<ProtoField name="users" type="UserConfig[]">

Users for all handlers on this inbound

</ProtoField>

<h3 id="inbound-security">Security</h3>

Per entry in `securityConfigs`

<ProtoField name="tls" type="TlsConfig">

Applied when this security block matches

</ProtoField>

<ProtoField name="reality" type="RealityConfig">

Applied when this security block matches

</ProtoField>

<ProtoField name="domains">

SNI hostnames handled by this block

</ProtoField>

<ProtoField name="regularExpression">

SNI regex match

</ProtoField>

<ProtoField name="always">

Use this security for every connection

</ProtoField>

<h3 id="inbound-transport-protocol">Transport protocol</h3>

Per entry in `transportProtocols`

<ProtoField name="websocket, http, grpc, httpupgrade, splithttp, tcp">

Transport-specific config (oneof)

</ProtoField>


<ProtoField name="alpn">

Match ALPN

</ProtoField>

<ProtoField name="sni">

Match connection SNI

</ProtoField>

<ProtoField name="path">

HTTP/1 path

</ProtoField>

<ProtoField name="h2">

Connection uses HTTP/2

</ProtoField>

<ProtoField name="always">

Use this transport for every connection

</ProtoField>

See [Transport](/docs/vx-core/configuration/transport) and [Security](/docs/vx-core/configuration/security) for field reference.
