Inbound configuration lives in `ServerConfig.inbounds` and `ServerConfig.multiInbounds`.

Schema definition: [`protos/proto/vx/inbound/inbound.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/inbound/inbound.proto).

## ProxyInboundConfig

A standard inbound. You can specify multiple proxy protocols, but only one transport protocol and one security protocol may be active.

<ProtoField name="tag" type="string">

Name referenced by [router](/docs/vx-core/configuration/router) `inboundTags`

</ProtoField>

<ProtoField name="address" type="string">

Listen address; empty means all interfaces

</ProtoField>

<ProtoField name="port" type="uint32">

Single port (can be set alongside `ports`)

</ProtoField>

<ProtoField name="ports" type="uint32[]">

List of ports to listen on

</ProtoField>

<ProtoField name="transport" type="TransportConfig">

TLS, REALITY, WebSocket, gRPC, etc.

</ProtoField>

<ProtoField name="protocol" type="Any">

One proxy server configuration (VMess, VLESS, Trojan, etc.)

</ProtoField>

<ProtoField name="protocols" type="Any[]">

Multiple protocols on the same listener

</ProtoField>

<ProtoField name="users" type="UserConfig[]">

Users for this inbound (see [Users](/docs/vx-core/configuration/users))

</ProtoField>

Example:

```json
{
  "tag": "vmess",
  "ports": [10000],
  "protocol": {
    "@type": "type.googleapis.com/vx.proxy.vmess.VmessServerConfig",
    "secureEncryptionOnly": true
  }
}
```

Protocol `@type` values are listed in [Proxy protocols](/docs/vx-core/configuration/protocols). Transport and TLS/REALITY: [Transport](/docs/vx-core/configuration/transport), [Security](/docs/vx-core/configuration/security).

> **Note**: When multiple protocols support UDP, only one protocol's UDP will actually take effect. If Hysteria is present, it is preferred and UDP for other protocols will not be enabled.

## MultiProxyInboundConfig

Multi-inbounds can use **multiple transport and security configurations** simultaneously.

<ProtoField name="tag" type="string">

Inbound tag for routing

</ProtoField>

<ProtoField name="address" type="string">

Listen address; empty means all interfaces

</ProtoField>

<ProtoField name="ports" type="uint32[]">

Listen ports

</ProtoField>

<ProtoField name="protocols" type="Any[]">

Proxy protocol configurations (same `Any` type as above)

</ProtoField>

<ProtoField name="securityConfigs" type="Security[]">

Security protocols

</ProtoField>

<ProtoField name="transportProtocols" type="Protocol[]">

Transport protocols

</ProtoField>

<ProtoField name="socket" type="SocketConfig">

Socket options

</ProtoField>

<ProtoField name="users" type="UserConfig[]">

Users for all handlers on this inbound

</ProtoField>

<h3 id="inbound-security">Security</h3>

Each entry in `securityConfigs`

Only one of `tls` or `reality` may be set per security block.

<ProtoField name="tls" type="TlsConfig">

</ProtoField>

<ProtoField name="reality" type="RealityConfig">

</ProtoField>

<ProtoField name="domains" type="string[]">

Use this security configuration for the specified SNI

</ProtoField>

<ProtoField name="regularExpression" type="string">

Use this security configuration for SNI matching this regular expression

</ProtoField>

<ProtoField name="always"  type="bool">

Use this security configuration for all connections

</ProtoField>

<h3 id="inbound-transport-protocol">Transport protocol</h3>

Each entry in `transportProtocols`

Only one of `websocket`, `http`, `grpc`, `httpupgrade`, `splithttp`, or `tcp` may be set per transport block.

<ProtoField name="websocket" type="WebsocketConfig">

WebSocket transport. See [WebSocket](/docs/vx-core/configuration/transport/websocket).

</ProtoField>

<ProtoField name="http" type="HttpConfig">

HTTP/2 transport camouflage. See [HTTP transport](/docs/vx-core/configuration/transport/http).

</ProtoField>

<ProtoField name="grpc" type="GrpcConfig">

gRPC transport. See [gRPC](/docs/vx-core/configuration/transport/grpc).

</ProtoField>

<ProtoField name="httpupgrade" type="HttpUpgradeConfig">

HTTP Upgrade transport. See [HTTPUpgrade](/docs/vx-core/configuration/transport/httpupgrade).

</ProtoField>

<ProtoField name="splithttp" type="SplitHttpConfig">

Split HTTP (XHTTP) transport. See [SplitHTTP](/docs/vx-core/configuration/transport/splithttp).

</ProtoField>

<ProtoField name="tcp" type="TcpConfig">

Plain TCP transport. See [TCP](/docs/vx-core/configuration/transport/tcp).

</ProtoField>

<ProtoField name="alpn" type="string">

Match ALPN

</ProtoField>

<ProtoField name="sni" type="string">

Match connection SNI

</ProtoField>

<ProtoField name="path" type="string">

HTTP/1 path

</ProtoField>

<ProtoField name="h2" type="bool">

Connection uses HTTP/2

</ProtoField>

<ProtoField name="always" type="bool">

Use this transport for all connections

</ProtoField>

Field details are in [Transport](/docs/vx-core/configuration/transport) and [Security](/docs/vx-core/configuration/security).
