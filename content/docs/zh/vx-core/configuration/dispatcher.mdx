调度器在 `ServerConfig.dispatcher`（`DispatcherConfig`）中配置。模式定义：[`protos/proto/vx/dispatcher/dispatcher.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/dispatcher/dispatcher.proto)。

所有的入站，DNS服务器的流量都会经过调度器。调度器会通过路由来选择一个节点，然后把流量交给此节点处理。

## DispatcherConfig

<ProtoField name="destinationOverride" type="string[]">

非空时嗅探连接，协议匹配时用嗅探域名覆盖目标

</ProtoField>

<ProtoField name="sniff" type="bool">

嗅探所有的连接，以获取额外连接元数据，这些数据可以使日志更全面

</ProtoField>

<ProtoField name="fallbackTimeout" type="uint32">

等待响应数据的时长（毫秒），若此时间内没有收到响应数据，将连接视为失败，开始回退

</ProtoField>

<ProtoField name="sessionStats" type="bool">

启用会话计量统计，日志内会显示

</ProtoField>

## 示例

```json
{
  "dispatcher": {
    "sniff": true,
    "destinationOverride": ["http", "tls"],
    "sessionStats": false
  }
}
```
