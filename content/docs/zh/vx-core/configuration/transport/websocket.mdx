## WebsocketConfig

<ProtoField name="host" type="string">

Host 头 / authority

</ProtoField>

<ProtoField name="path" type="string">

URL 路径；空 = `/`

</ProtoField>

<ProtoField name="header" type="Header[]">

额外头（`key`、`value`）

</ProtoField>

<ProtoField name="maxEarlyData" type="int32">

最大 early data 字节数

</ProtoField>

<ProtoField name="useBrowserForwarding" type="bool">

浏览器转发模式

</ProtoField>

<ProtoField name="earlyDataHeaderName" type="string">

携带 early data 的头

</ProtoField>

### Header

<ProtoField name="key" type="string">

头名称

</ProtoField>

<ProtoField name="value" type="string">

头值

</ProtoField>

```json
{
  "transport": {
    "websocket": {
      "path": "/ray",
      "host": "example.com"
    },
    "tls": { "serverName": "example.com" }
  }
}
```

亦嵌入 [HTTPUpgrade](/zh/docs/vx-core/configuration/transport/httpupgrade)。
