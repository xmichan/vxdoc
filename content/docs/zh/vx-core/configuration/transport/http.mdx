Proto：[`protos/proto/vx/transport/protocols/http/config.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/transport/protocols/http/config.proto)

HTTP/2 传输伪装（不是 [HTTP proxy](/zh/docs/vx-core/configuration/protocols/http-proxy) 协议）。设置在 `TransportConfig.http`。

## HttpConfig

<ProtoField name="host" type="string[]">

Host 头值（随机选取）

</ProtoField>

<ProtoField name="path" type="string">

请求路径

</ProtoField>

<ProtoField name="method" type="string">

HTTP 方法

</ProtoField>

<ProtoField name="header" type="HttpHeader[]">

自定义头，见 [HttpHeader](#httpheader)

</ProtoField>

### HttpHeader

<ProtoField name="name" type="string">

头名称（如 `Accept`、`Cookie`）

</ProtoField>

<ProtoField name="value" type="string[]">

头值；多项时随机选取一项

</ProtoField>

```json
{
  "transport": {
    "http": {
      "host": ["example.com"],
      "path": "/download",
      "method": "GET"
    },
    "tls": { "serverName": "example.com" }
  }
}
```
