传输设置通过 [入站](/zh/docs/vx-core/configuration/inbounds) 与 [出站](/zh/docs/vx-core/configuration/outbounds) 的 `transport: { ... }` 包装代理协议。

根消息：[`TransportConfig`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/transport/transport.proto)，位于 `protos/proto/vx/transport/transport.proto`。

## TransportConfig

<ProtoField name="socket" type="SocketConfig">

套接字选项（mark、TFO、绑定、缓冲区等）。见 [Socket](/zh/docs/vx-core/configuration/transport/socket)。

</ProtoField>

### 线路协议（oneof）

`tcp`、`kcp`、`websocket`、`http`、`grpc`、`httpupgrade`、`splithttp` 互斥，每个 `TransportConfig` 只能设置其中一项。

<ProtoField name="tcp" type="TcpConfig">

纯 TCP 传输。见 [TCP](/zh/docs/vx-core/configuration/transport/tcp)。

</ProtoField>

<ProtoField name="kcp" type="KcpConfig">

基于 UDP 的 KCP 传输。见 [KCP](/zh/docs/vx-core/configuration/transport/kcp)。

</ProtoField>

<ProtoField name="websocket" type="WebsocketConfig">

WebSocket 传输。见 [WebSocket](/zh/docs/vx-core/configuration/transport/websocket)。

</ProtoField>

<ProtoField name="http" type="HttpConfig">

HTTP/2 传输伪装。见 [HTTP transport](/zh/docs/vx-core/configuration/transport/http)。

</ProtoField>

<ProtoField name="grpc" type="GrpcConfig">

gRPC 传输。见 [gRPC](/zh/docs/vx-core/configuration/transport/grpc)。

</ProtoField>

<ProtoField name="httpupgrade" type="HttpUpgradeConfig">

HTTP Upgrade 传输。见 [HTTPUpgrade](/zh/docs/vx-core/configuration/transport/httpupgrade)。

</ProtoField>

<ProtoField name="splithttp" type="SplitHttpConfig">

Split HTTP (XHTTP) 传输。见 [SplitHTTP](/zh/docs/vx-core/configuration/transport/splithttp)。

</ProtoField>

### 安全层（oneof）

`tls` 与 `reality` 互斥。见[安全](/zh/docs/vx-core/configuration/security)。

<ProtoField name="tls" type="TlsConfig">

TLS 证书、SNI、uTLS、ECH

</ProtoField>

<ProtoField name="reality" type="RealityConfig">

REALITY 伪装

</ProtoField>

### 扩展

<ProtoField name="transportProtocol" type="Any">

自定义传输协议的 `Any` 逃生舱

</ProtoField>

<ProtoField name="securityProtocol" type="Any">

自定义安全协议的 `Any` 逃生舱

</ProtoField>

每个配置应只设置一个**线路协议**与一个**安全**字段（或均不设置）。

## 示例（VLESS + WebSocket + TLS）

```json
{
  "tag": "vless-ws",
  "ports": [443],
  "transport": {
    "websocket": { "path": "/ws", "host": "example.com" },
    "tls": {
      "serverName": "example.com",
      "certificates": [
        { "certificateFilepath": "/etc/vx/cert.pem", "keyFilepath": "/etc/vx/key.pem" }
      ]
    }
  },
  "protocol": {
    "@type": "type.googleapis.com/vx.proxy.vless.VlessServerConfig",
    "users": [{ "id": "uuid" }]
  }
}
```

## 多入站传输矩阵

在 `MultiProxyInboundConfig` 上，传输协议在 `transportProtocols[]` 中按 ALPN/SNI/路径选择，而非单一 `TransportConfig`。`securityConfigs[]` 中的安全块同理。见[入站](/zh/docs/vx-core/configuration/inbounds)。
