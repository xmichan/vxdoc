Proto：[`protos/proto/vx/transport/protocols/kcp/config.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/transport/protocols/kcp/config.proto)

基于 UDP 的 KCP 传输。设置在 `TransportConfig.kcp`。

## KcpConfig

<ProtoField name="mtu" type="uint32">

MTU

</ProtoField>

<ProtoField name="tti" type="uint32">

传输时间间隔

</ProtoField>

<ProtoField name="uplinkCapacity" type="uint32">

上行容量（旧式调参）

</ProtoField>

<ProtoField name="downlinkCapacity" type="uint32">

下行容量

</ProtoField>

<ProtoField name="congestion" type="bool">

启用拥塞控制

</ProtoField>

<ProtoField name="writeBuffer" type="uint32">

写缓冲区大小

</ProtoField>

<ProtoField name="readBuffer" type="uint32">

读缓冲区大小

</ProtoField>

<ProtoField name="headerConfig" type="Any">

包头伪装（与 [TCP 头](/zh/docs/vx-core/configuration/transport/tcp) 同族）

</ProtoField>

<ProtoField name="seed" type="string">

混淆种子

</ProtoField>

```json
{
  "transport": {
    "kcp": {
      "mtu": 1350,
      "tti": 50,
      "uplinkCapacity": 12,
      "downlinkCapacity": 100
    }
  }
}
```
