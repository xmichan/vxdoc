所有的出站都将由此工厂生成。
模式定义：[`protos/proto/vx/dialerfactory/dialerfactory.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/dialerfactory/dialerfactory.proto)。

被用于`ServerConfig.dialerFactory`。

## DialerFactoryConfig

<ProtoField name="dialTimeout" type="uint32">

连接超时（秒）

</ProtoField>

<ProtoField name="shouldBindDevice" type="bool">

将Socket绑定到默认物理网络NIC

</ProtoField>

<ProtoField name="useInternalResolver" type="bool">

拨号解析域名时使用 [内部DNS解析器](/zh/docs/vx-core/configuration/dns) `internalResolver`

</ProtoField>

## 示例

```json
{
  "dialerFactory": {
    "dialTimeout": 10,
    "shouldBindDevice": false,
    "useInternalResolver": true
  }
}
```
