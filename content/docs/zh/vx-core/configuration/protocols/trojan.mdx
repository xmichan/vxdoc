## TrojanServerConfig

<ProtoField name="users" type="UserConfig[]">

密码在 `secret` 中

</ProtoField>

<ProtoField name="vision" type="bool">

启用 **Trojan Vision**（与 VLESS 的 `xtls-rprx-vision` 类似）。客户端与服务器须**同时**开启。

</ProtoField>

```json
{
  "@type": "type.googleapis.com/vx.proxy.trojan.TrojanServerConfig",
  "vision": true,
  "users": [{ "id": "user1", "secret": "your-password" }]
}
```
