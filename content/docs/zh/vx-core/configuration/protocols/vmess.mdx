## VmessServerConfig

<ProtoField name="accounts" type="UserConfig[]">

允许的用户（`id`、`userLevel`、`secret`）

</ProtoField>

<ProtoField name="secureEncryptionOnly" type="bool">

拒绝旧版加密

</ProtoField>

```json
{
  "@type": "type.googleapis.com/vx.proxy.vmess.VmessServerConfig",
  "secureEncryptionOnly": true,
  "accounts": [{ "id": "uuid-here", "userLevel": 0 }]
}
```

## VmessClientConfig

<ProtoField name="id" type="string">

类似于密码，可以是任意string

</ProtoField>

<ProtoField name="security" type="SecurityType">

见下方

</ProtoField>


<ProtoField name="alterId" type="uint32">

旧版 alterId（通常为 0）

</ProtoField>

### SecurityType

<ProtoField name="UNKNOWN" type="0" />

<ProtoField name="LEGACY" type="1" />

<ProtoField name="AUTO" type="2" />

<ProtoField name="AES128_GCM" type="3" />

<ProtoField name="CHACHA20_POLY1305" type="4" />

<ProtoField name="NONE" type="5" />

<ProtoField name="ZERO" type="6" />

JSON 中使用枚举名（例如 `"security": "CHACHA20_POLY1305"`）。
