DNS 在 `ServerConfig.dns`（`DnsConfig`）中配置。模式定义：[`protos/proto/vx/dns/dns.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/dns/dns.proto)。

## DnsConfig

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `records` | `Record[]` | 静态域名 → IP 映射 |
| `recordStrings` | string[] |  静态域名 → IP 映射 |
| `dnsServers` | `DnsServerConfig[]` |  DNS服务器 |
| `internalResolver` | `Resolver` | 出站**拨号**时使用此解析器解析域名 |
| `requestDomainResolver` | `Resolver` | **路由** 使用此解析器解析域名 |
| `concurrentDnsServers` | `ConcurrentDnsServer[]` | 并行查询DNS服务器 |
| `serialDnsServers` | `SerialDnsServer[]` | 依次查询DNS服务器 |
| `dnsHijack` | `DnsHijackConfig` | Dns劫持 |

### Record

| 字段 | 说明 |
| --- | --- |
| `domain` | 主机名 |
| `ip` | 静态应答 |
| `proxiedDomain` | 将此域名映射为与 `proxiedDomain` 相同的 IP |

### Resolver

| 字段 | 说明 |
| --- | --- |
| `dnsServers` | 使用到的DNS服务器 |
| `interval` | 串行行为中的重试间隔 |
| `name` | 解析器名称 |

## DnsServerConfig

每台服务器有 `name` 与 `type` oneof：

| 类型 | 消息 | 用途 |
| --- | --- | --- |
| `plainDnsServer` | `PlainDnsServer` | UDP/TCP DNS |
| `tlsDnsServer` | `TlsDnsServer` | DNS over TLS |
| `dohDnsServer` | `DohDnsServer` | DNS over HTTPS |
| `quicDnsServer` | `QuicDnsServer` | DNS over QUIC |
| `fakeDnsServer` | `FakeDnsServer` | Fake IP 池（`poolConfigs`：`cidr`、`lruSize`） |
| `goDnsServer` | `GoDnsServer` | Go默认解析器 |
| `emptyDnsServer` | `EmptyDnsServer` | 返回空的解析 |

通用字段：

| 字段 | 说明 |
| --- | --- |
| `clientIp` | EDNS 客户端子网 |
| `cacheDuration` | 覆盖 TTL 缓存；`0` 表示使用应答最小 TTL |
| `ipTags` | 丢弃不在这些 [geo](/zh/docs/vx-core/configuration/geo) IP 集合内的应答 |

## DnsHijackConfig

| 字段 | 说明 |
| --- | --- |
| `dnsRules` | `DnsRuleConfig[]` — 按域名/标签/类型选择服务器 |
| `enableFakeDns` | 为被劫持查询启用 Fake DNS |

### DnsRuleConfig

| 字段 | 说明 |
| --- | --- |
| `dnsServerName` | 目标 `DnsServerConfig.name` |
| `domains`、`domainTags` | 匹配查询名 |
| `includedTypes` | `A`、`AAAA`、`HTTPS` 等 |
| `ruleName` | 调试标签 |
