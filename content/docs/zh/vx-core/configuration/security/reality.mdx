Proto：[`protos/proto/vx/transport/security/reality/config.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/transport/security/reality/config.proto)

设置在 `TransportConfig.reality` 或 `MultiProxyInboundConfig.securityConfigs[].reality`。

与 `tls` **互斥**（同一传输块只能二选一）。

## RealityConfig

### 仅服务端

<ProtoField name="dest" type="string">

回退目标（例如 `www.microsoft.com:443`）

</ProtoField>

<ProtoField name="xver" type="uint64">

发往 `dest` 的 PROXY protocol 版本（0 = 不发送）

</ProtoField>

<ProtoField name="serverNames" type="string[]">

允许的 SNI 服务器名

</ProtoField>

<ProtoField name="privateKey" type="bytes">

X25519 私钥

</ProtoField>

<ProtoField name="minClientVer" type="bytes">

允许的客户端最低版本字节

</ProtoField>

<ProtoField name="maxClientVer" type="bytes">

允许的客户端最高版本字节

</ProtoField>

<ProtoField name="maxTimeDiff" type="uint64">

最大客户端时钟偏差（**毫秒**）

</ProtoField>

<ProtoField name="shortIds" type="bytes[]">

允许的 short ID 列表（每项最多 8 字节）

</ProtoField>

### 客户端

<ProtoField name="show" type="bool">

调试输出

</ProtoField>

<ProtoField name="Fingerprint" type="string">

uTLS 指纹（如 `chrome`、`firefox`）

</ProtoField>

<ProtoField name="serverName" type="string">

呈现的 SNI

</ProtoField>

<ProtoField name="publicKey" type="bytes">

服务端公钥（字节）

</ProtoField>

<ProtoField name="pbk" type="string">

公钥（Base64 字符串，与 `publicKey` 等价表示）

</ProtoField>

<ProtoField name="shortId" type="bytes">

客户端 short ID（字节，须 8 字节）

</ProtoField>

<ProtoField name="sid" type="string">

Short ID 十六进制字符串（8 字节）

</ProtoField>

<ProtoField name="spiderX" type="string">

Spider X 路径

</ProtoField>

<ProtoField name="spiderY" type="int64[]">

Spider Y 值列表

</ProtoField>

<ProtoField name="masterKeyLog" type="string">

密钥日志路径（调试）

</ProtoField>

```json
{
  "transport": {
    "tcp": {},
    "reality": {
      "dest": "www.microsoft.com:443",
      "serverNames": ["www.example.com"],
      "privateKey": "base64-or-raw",
      "shortIds": ["", "0123456789abcdef"]
    }
  },
  "protocol": {
    "@type": "type.googleapis.com/vx.proxy.vless.VlessServerConfig",
    "users": [{ "id": "uuid", "flow": "" }]
  }
}
```
