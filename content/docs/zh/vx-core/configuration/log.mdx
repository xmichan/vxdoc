日志在 `ServerConfig.log`（`LoggerConfig`）中配置。模式定义：[`protos/proto/vx/log/logger.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/log/logger.proto)。

## LoggerConfig

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `logLevel` | `Level` | 最低级别：`DEBUG`、`INFO`、`WARN`、`ERROR`、`FATAL`、`DISABLED` |
| `filePath` | string | 日志文件路径 |
| `logFileDir` | string | `filePath` 为空时，在此目录写入带时间戳的文件（`2006-01-02T15:04:05.txt`） |
| `consoleWriter` | bool | 人类可读的控制台输出 |
| `showColor` | bool | 彩色日志（配合控制台输出） |
| `showCaller` | bool | 包含调用位置 |
| `redact` | bool | 在日志行中脱敏域名与 IP |

## 示例

```json
{
  "log": {
    "logLevel": "INFO",
    "filePath": "/var/log/vx/vx.log",
    "redact": false
  }
}
```

## UserLoggerConfig

同一 proto 文件中的 `UserLoggerConfig` 用于 **VX 客户端**会话日志（`enable`、`logAppId`、`logSessionEnd`、`logRealtimeUsage`）。不属于 `ServerConfig`；由客户端单独接入。
