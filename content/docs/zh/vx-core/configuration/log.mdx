日志在 `ServerConfig.log`（`LoggerConfig`）中配置。模式定义：[`protos/proto/vx/log/logger.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/log/logger.proto)。

## LoggerConfig

<ProtoField name="logLevel" type="Level">

最低级别：`DEBUG`、`INFO`、`WARN`、`ERROR`、`FATAL`、`DISABLED`

</ProtoField>

<ProtoField name="filePath" type="string">

日志文件路径

</ProtoField>

<ProtoField name="logFileDir" type="string">

`filePath` 为空时，在此目录写入带时间戳的文件（`2006-01-02T15:04:05.txt`）

</ProtoField>

<ProtoField name="consoleWriter" type="bool">

人类可读的控制台输出

</ProtoField>

<ProtoField name="showColor" type="bool">

彩色日志（配合控制台输出）

</ProtoField>

<ProtoField name="showCaller" type="bool">

包含调用位置

</ProtoField>

<ProtoField name="redact" type="bool">

在日志行中脱敏域名与 IP

</ProtoField>

## 示例

```json
{
  "log": {
    "logLevel": "INFO",
    "filePath": "/var/log/vx/vx.log",
    "redact": false
  }
}
```
