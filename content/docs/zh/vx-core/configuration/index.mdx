vx-core 读取单个**服务器配置文件**。根消息为 [`protos/proto/vx/server.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/server.proto) 中的 `ServerConfig`。

## 配置格式

配置为 protobuf 消息，可序列化为：

- **二进制 protobuf** — 紧凑；部分内部路径使用
- **ProtoJSON** — 人类可读的 JSON；适合手工编辑

协议与传输的类型化设置使用 `google.protobuf.Any`。在 JSON 中，将 `@type` 设为消息的类型 URL：

```json
{
  "@type": "type.googleapis.com/vx.proxy.trojan.TrojanServerConfig",
  "users": [{ "secret": "your-password" }]
}
```

JSON 字段名使用 **camelCase**（例如 `matchAll`、`outboundTag`、`multiInbounds`）。

## ServerConfig 概览

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `inbounds` | `ProxyInboundConfig[]` | 单协议监听器 |
| `multiInbounds` | `MultiProxyInboundConfig[]` | 多协议监听器（TLS/REALITY + 传输矩阵） |
| `outbounds` | `OutboundHandlerConfig[]` | 流量去向（直连、代理、阻断等） |
| `router` | `RouterConfig` | 按连接选择出站或选择器的规则 |
| `dns` | `DnsConfig` | DNS 服务器、解析器、劫持、静态记录 |
| `geo` | `GeoConfig` | 路由与 DNS 使用的域名/IP/应用集合 |
| `policy` | `PolicyConfig` | 超时与按级别的缓冲区限制 |
| `log` | `LoggerConfig` | 日志级别、文件路径、脱敏 |
| `users` | `UserConfig[]` | 全局用户（也可按入站附加） |
| `dispatcher` | `DispatcherConfig` | 嗅探与目标覆盖 |
| `dialerFactory` | `DialerFactoryConfig` | 出站拨号超时与解析器绑定 |

最小服务器示例：

```json
{
  "inbounds": [
    {
      "tag": "trojan",
      "ports": [443],
      "protocol": {
        "@type": "type.googleapis.com/vx.proxy.trojan.TrojanServerConfig"
      }
    }
  ],
  "router": {
    "rules": [{ "matchAll": true, "outboundTag": "direct" }]
  },
  "outbounds": [
    {
      "tag": "direct",
      "protocol": {
        "@type": "type.googleapis.com/vx.proxy.freedom.FreedomConfig"
      }
    }
  ]
}
```

## CLI

```bash
vx run --config config.json
```

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--config` | `config.json` | 配置文件路径 |

通过[安装脚本](/zh/docs/vx-core/quick-start)安装时，默认路径为 `/usr/local/etc/vx/config.json`。
