地理数据集合在 `ServerConfig.geo`（`GeoConfig`）中定义。模式定义：[`protos/proto/vx/geo/geo.proto`](https://github.com/5vnetwork/vx-core/blob/main/protos/proto/vx/geo/geo.proto)。

[路由](/zh/docs/vx-core/configuration/router)规则与 [DNS](/zh/docs/vx-core/configuration/dns) 通过 `domainTags`、`dstIpTags`、`srcIpTags` 按**名称**引用集合。

## GeoConfig

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `greatDomainSets` | `GreatDomainSetConfig[]` | 大域名集合|
| `atomicDomainSets` | `AtomicDomainSetConfig[]` | 小域名集合 |
| `greatIpSets` | `GreatIPSetConfig[]` | 大IP集合 |
| `atomicIpSets` | `AtomicIPSetConfig[]` | 小IP集合 |
| `appSets` | `AppSetConfig[]` | 应用集合 |

各类别内名称须唯一（`greatDomainSets` 与 `atomicDomainSets` 之间不可重名，IP 集合同理）。

## AtomicDomainSetConfig

| 字段 | 说明 |
| --- | --- |
| `name` | `domainTags` 中使用的标签 |
| `domains` | 一些单独的 `Domain` 列表 |
| `geosite`、`geosites` | 从 geosite 文件或远程加载 |
| `useBloomFilter` | 布隆过滤器优化，通常在iOS端开启以减少内存占用 |
| `clashFiles` | Clash 格式规则文件 |
| `inverse` | 反向匹配 |
| `remoteGeoFiles` | 从URL下载文件  |

### GeositeConfig

| 字段 | 说明 |
| --- | --- |
| `codes` | Geosite 分类代码 |
| `attributes` | 属性过滤 |
| `filepath` | 本地 geosite.dat 路径 |
| `remoteUrl` | 远程文件URL  |
| `refreshCron` | 多久更新一次文件 |

## AtomicIPSetConfig

| 字段 | 说明 |
| --- | --- |
| `name` | `IpTags` 中使用的标签 |
| `cidrs` | CIDR 列表 |
| `geoip` | `GeoIPConfig` |
| `inverse` | 匹配集合外的 IP |
| `clashFiles` | Clash文件 |
| `remoteGeoFiles` | 从URL下载文件 |

### GeoIPConfig

| 字段 | 说明 |
| --- | --- |
| `codes` | 国家代码 |
| `filepath` | 文件路径，若为空，会从remoteUrl下载文件到此路径 |
| `remoteUrl` | 远程文件URL |
| `refreshCron` | 多久更新一次文件 |

## GreatDomainSetConfig / GreatIPSetConfig

大集合：

| 字段 | 说明 |
| --- | --- |
| `name` | 结果集合名称 |
| `oppositeName` | 互斥集合名称 |
| `inNames` | 包含这些集合 |
| `exNames` | 排除这些集合 |

大集合由其他大集合或者小集合构成。

## AppSetConfig

| 字段 | 说明 |
| --- | --- |
| `name` | 路由规则中 `appTags` 引用 |
| `appIds` | `AppId` 条目（`keyword`、`prefix` 或 `exact`） |
| `clashFiles` | Clash 规则文件 |

## GeoRemoteFile

用于 atomic 集合下的定时下载：

| 字段 | 说明 |
| --- | --- |
| `filepath` | 写入的本地路径 |
| `sourceUrl` | HTTPS URL |
| `refreshCron` | 5 段 cron；空表示仅在启动/重载时拉取 |
