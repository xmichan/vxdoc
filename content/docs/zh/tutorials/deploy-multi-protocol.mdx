VX **All in One** Quick Deploy 可在 VPS 上安装 **vx-core**，并在单次部署中创建多个节点。部署的节点使用自签名证书并启用 SHA256 对等验证，因此无需担心 MITM 攻击。

典型的 All-in-One 部署包括：

- **协议** — VMess、Trojan、AnyTLS 与 Hysteria2
- **传输** — WebSocket 与 gRPC
- **安全** — 基于生成证书的 TLS；提供 REALITY 域名时可选用 **REALITY**
- **CDN** — 可选 CDN 主机名，在服务器前端增加 WebSocket + TLS 节点

VX 还可在部署时按需启用 **BBR** 并调整防火墙设置。
