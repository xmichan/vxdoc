---
title: UWP 环回豁免（Windows）
description: 允许 Microsoft Store（UWP）应用通过 localhost 连接 VX
---

在 Windows 上，**UWP 应用**（从 Microsoft Store 安装的应用）默认无法连接 `127.0.0.1` 及其他环回地址。该限制会导致在使用 VX 系统代理入站模式时，来自 Store 应用的流量无法进入 VX。

本教程说明如何 **解除 UWP 环回限制**，使 Store 应用在使用系统代理入站模式时也能被代理。若使用 TUN 模式，可跳过此步骤，因为 TUN 模式会处理所有网络流量。
