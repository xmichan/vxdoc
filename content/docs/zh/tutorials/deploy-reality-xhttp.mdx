description: 使用 VX Quick Deploy 安装 Xray 并在 VPS 上发布 REALITY 与 XHTTP 入站

VX 可在 VPS 上部署 **REALITY** 与 **XHTTP**（SplitHTTP）节点，无需手动编辑配置文件。在已连接的服务器上，使用 **Quick Deploy → Reality/XHTTP**：VX 会安装 Xray-core、写入入站配置、在需要时启用 BBR，并向客户端添加匹配的 **出站节点**，以便立即连接。

<Callout type="warn">
  若服务器上已安装 Xray，此部署配置**会替换现有的 Xray 配置**。
</Callout>

## 前置条件

- 可通过 **SSH** 访问的 Linux VPS（已在 VX 的 **Servers** 中添加）
- 用作 REALITY **destination** / SNI 目标的域名或站点（如视频所示）
- 可选：若通过 CDN 前置 XHTTP，需提供 **CDN 主机名**
