---
title: HTTP/SOCKS 服务器
description: 将代理连接共享为本地 HTTP 或 SOCKS 服务器
---

VX 可暴露本地 HTTP 和/或 SOCKS5 服务器，让网络上其他设备或应用使用同一代理连接。

## 代理共享模式

启用后，vx-core 在可配置的地址与端口监听，接受 HTTP CONNECT 与 SOCKS5 连接。这些客户端的流量与 VX 应用本身使用相同的出站与规则路由。

## 系统代理模式

此外，VX 可在不启用完整 TUN 的情况下设置 **系统代理**（localhost 上的 HTTP + SOCKS）：

- 比 TUN 模式更轻量
- 适用于尊重系统代理设置的应用
- 可动态分配端口以避免冲突

## 使用场景

- 与局域网内的游戏机或电视共享 VPN/代理连接
- 让其他浏览器或工具使用 VX，无需单独安装
- 针对当前路由设置测试客户端

## 设置

- 监听地址（默认 localhost；可绑定到局域网接口以共享）
- 端口（固定或动态分配）
- SOCKS5 的 UDP 支持

## 安全说明

绑定到 `0.0.0.0` 会将代理暴露给本地网络。仅在可信网络上启用局域网共享，并考虑防火墙规则。
