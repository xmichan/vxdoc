title: VPS 监控
description: 通过 SSH 监控远程服务器状态
---

**服务器** 标签页可让您通过 SSH 连接 Linux VPS，并实时监控 vx-core 运行时状态。

## 监控指标

- **已安装** — 服务器上是否存在 vx-core
- **版本** — 运行中的 vx-core 版本
- **运行时间** — 服务启动时间
- **内存** — 当前内存占用

## 服务器操作

在同一面板中可：

- 关闭或重启 VPS
- 启动、停止或重启 vx-core 服务
- 安装、更新或卸载 vx-core

## 设置

添加服务器时提供 SSH 凭据（主机、端口、用户名、密钥或密码）。VX 将VPS密码等机密加密存储在本地。
