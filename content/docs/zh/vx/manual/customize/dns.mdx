DNS 服务器由每个[路由模式](/zh/docs/vx/manual/customize/modes)内的 **DNS 规则** 引用。
当 vx-core 在拨号出站时解析域名时，也用作 **内部 DNS 服务器**。

## DNS 查询如何处理

有两类查询：

**劫持 DNS** — 来自其他应用的查询（TUN 模式或系统 DNS 指向 vx-core 时）。与 Dns 规则匹配。

**内部 DNS** — 当 vx-core 自身需要解析域名时（例如域名为地址的节点）。按模式有序的 **内部 DNS 服务器** 列表从左到右依次尝试，直到成功。

对 **两类** 查询，都会先检查 **DNS 记录**。若记录匹配查询，vx-core 立即返回该答案，不再转发到 DNS 服务器。

## DNS 服务器类型

添加 **DNS 服务器** 时，从下拉菜单选择类型。每种类型为单一解析器实现。

| 类型 | 作用 |
| --- | --- |
| **Fake** | 从配置的 CIDR 池（通常为 `198.18.0.0/15`）返回假 IP。 |
| **UDP/TCP** | 经典 DNS over UDP/TCP，指向一个或多个 `host:port`。多个地址可用逗号分隔；每次查询同时发往所有地址，使用 **首个回复**。 |
| **HTTPS** | DNS over HTTPS (DoH)，指向解析器 URL（例如 `https://1.1.1.1/dns-query`）。 |
| **TLS** | DNS over TLS (DoT)，指向一个或多个 `host:port`。 |
| **QUIC** | DNS over QUIC。 |
| **Go** | 使用 Go 运行时 / 系统 DNS 解析器（操作系统解析行为）。其流量不经过路由，通常用于服务器与非 TUN 模式。 |
| **Empty** | 始终返回空 DNS 应答（无记录）。 |

### 通用字段（多数类型）

| 字段 | 用途 |
| --- | --- |
| **Name** | 在 DNS 规则与内部 DNS 服务器列表中使用的唯一标签。不可与其他服务器或组合名称重复。名称 `hijack` 保留。 |
| **Client IP** | 可选 ECS (EDNS Client Subnet) 源地址，随查询发送，使上游解析器返回您所在位置的答案。 |
| **Cache duration** | 缓存响应的秒数。若为空或 `0`，则缓存至记录 TTL 过期。 |
| **Result IP set** | 解析后丢弃 A/AAAA 答案中 **不在** 所选 IP 集合内的 IP。可用于防止 DNS 污染 |

### Fake DNS 字段

| 字段 | 用途 |
| --- | --- |
| **Pool** | 假 IP 分配的逗号分隔 CIDR（例如 `198.18.0.0/15`）。 |
| **LRU size** | 每个池保留的假 DNS 映射数量（表单默认 6666）。 |

## 组合 DNS 服务器

除单一解析器外，还可创建 **组**，按名称组合其他 DNS 服务器：

### Concurrent DNS Server

**并行** 运行 **所有** 成员服务器，返回首个 **明确** 答案（NOERROR 且至少一条记录）。
若无服务器返回明确答案，则仅保留空的 NOERROR 作为回退。

当您希望从多个上游中选用最快解析器时使用（例如同时查询 `8.8.8.8` 与 `1.1.1.1`）。

### Serial DNS Server

**按顺序** 查询成员服务器，但若在 **间隔**（秒）内尚无明确答案，则启动下一个服务器。较早的查询仍在后台运行，因此较慢但正确的上游仍可能胜出。

当您希望主解析器配合定时回退时使用（例如先尝试国内 DNS，再尝试国外 DNS）。

两种组合类型至少需要一名成员 DNS 服务器。串行组的成员顺序很重要（可在表单中重排）。

## DNS 记录

每条记录包含：

| 字段 | 用途 |
| --- | --- |
| **Domain** | 要匹配的主机名（必填）。 |
| **IP addresses** | 逗号分隔的 IPv4 和/或 IPv6 地址。生成 **A** 与 **AAAA** 答案。 |
| **Proxied domain** | 可选 **CNAME** 目标 — 域名解析到该名称而非直接 IP。 |

### 应用于所有 DNS 查询

**DNS 记录对每条 DNS 查询都会评估** — 劫持的应用查询与 vx-core 内部查询均如此。

vx-core 在 DNS 规则与上游解析器 **之前** 检查静态记录。若查询名称与类型匹配记录，立即返回该答案。

适用于：

- 在不改路由规则的情况下阻断或重定向特定域名
- 将域名固定到指定 IP 用于测试
- 本地开发主机名
