**选择器** 从一组节点中为需代理的连接选择要使用的节点。

## 选择器筛选

**Range**（选择器筛选）定义选择器可从哪些节点中选择。

- **All Nodes**: 所有节点。
- **Partial Nodes**: 仅您指定的节点。

选择 **Partial Nodes** 时，使用筛选芯片缩小池范围。

- **Node**: 单个节点。
- **Group**: 节点组或订阅。
- **Prefix**: 名称以给定前缀开头的节点。
- **Sub String**: 名称包含给定子串的节点。
- **Area**: 该区域内的节点。

筛选更改立即生效，无需重启。

## 选择策略

筛选后，**Select Strategy** 决定从该池中 **实际使用** 哪些节点。

- **All**: 筛选池中的每个节点
- **Usable**: 所有可用节点
- **Lowest Latency**: ping 最低的单节点
- **Speed Highest**: 测速吞吐量最高的单节点
- **Low Latency**: ping 在最佳 ping **30%** 以内的所有节点（例如最佳 100 ms → 包含 ≤ 130 ms 的节点）
- **High Speed**: 吞吐量 ≥ 最佳的 **70%** 的所有节点（例如最佳 100 → 包含 ≥ 70 的节点）

选择 **单个** 节点的策略（**Lowest Latency**、**Speed Highest**）不显示负载策略 — 每条连接使用该单节点。

选择 **多个** 节点的策略（**All**、**Usable**、**Low Latency**、**High Speed**）下方显示 **Balance Strategy**。

### 测试间隔

每个选择器会定期测试节点。可配置测试方式：

- **Speed test size** (`1,000,000 字节 (1 MB)`): 每次测速的下载大小。
- **Speed test interval** (`60 分钟`): 对筛选节点测速的频率。
- **Ping test interval** (`10 分钟`): 对筛选节点 ping 的频率。
- **Unusable test interval** (`10 分钟`): 重新检查标记为不可用节点的频率。

仅 **Speed Highest** 与 **High Speed** 定期测速。仅 **Lowest Latency** 与 **Low Latency** 定期 ping。
除 **All** 外所有策略都会定期测试可用性与不可用节点。

## 负载策略

当选择策略保持 **多个** 节点活跃时，**Balance Strategy** 决定哪条连接由哪个节点处理：

- **Random**: 从活跃集合中为连接随机选节点。IPv6 流量在可用时优先选择支持 IPv6 的节点。
- **Memory**: 粘性：尽可能为同一 **应用** 或 **根域名** 复用同一节点。尚无映射时随机分配并记住。IPv6 流量优先选择支持 IPv6 的节点。

希望每个站点或应用出口稳定（会话中 IP 变化更少）时使用 **Memory**。希望在多节点间均匀分配负载时使用 **Random**。

> **说明：** 负载策略仅在选中多个节点时适用（**All**、**Usable**、**Low Latency** 或 **High Speed**）。不适用于 **Lowest Latency** 或 **Speed Highest**。

> **说明：** 每个选择器会测试节点是否支持 IPv6，确保 IPv6 连接不会发往不支持 IPv6 的节点。

## 节点链

**Node chain**（落地处理器）在选择器选中的节点 **之后** 将流量经额外代理跳发送。

流量路径：

```
[您的流量] → [选中的节点] → [节点链首节点] → … → [节点链末节点] → [目标]
```
**节点链** 列表中的 **最后一个** 节点为 **落地节点**（到达目标前的最终出口）。

当需要在选择器所选节点之上固定下游跳（例如经特定区域出口）时使用节点链。详见[链式代理](/zh/docs/vx/manual/chain-proxy)了解详情与限制。

## Proxy 选择器

该选择器较特殊，支持手动节点选择，即您在节点页手动选择要使用的节点。
使用手动节点选择时，节点页会显示开关。
