## 视频中用到的命令

<Tabs
  groupId="gcp-ssh-key"
  items={['Windows', 'macOS']}

  defaultIndex={0}
>
  <Tab value="Windows">

### 生成 SSH 密钥

```bash
mkdir .ssh & ssh-keygen -t rsa -f .ssh\gcp -N "" -C cat
```

### 复制公钥

```bash
type .ssh\gcp.pub | clip
```

### 复制私钥

```bash
type .ssh\gcp | clip
```

  </Tab>
  <Tab value="macOS">

### 生成 SSH 密钥

```bash
mkdir .ssh; ssh-keygen -t rsa -f ~/.ssh/gcp -C cat -N ""
```

### 复制公钥

```bash
cat .ssh/gcp.pub | pbcopy
```

### 复制私钥

```bash
cat .ssh/gcp | pbcopy
```
